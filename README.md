# Your mission
You are a child.
A simple child.
A simple human.
You have one mission, to get has many ballons has possible.
Time is no fact, time doesnt exist.
Get. Ballons.


# How to play

A and D to move left and right
W to jump AND to get the ballon


# Install
Just open index.html for web version
If there is a main.zip open it, extract it, and launch game.exe
